# Security Policy

Nvidium is a client-side Minecraft rendering mod. Security-relevant issues are rare, but if you find one
(for example a crash exploitable by untrusted server data, or unsafe native memory handling):

## Reporting

- Prefer [GitHub private vulnerability reporting](https://github.com/denfry/nvidium/security/advisories/new).
- Alternatively open a regular issue **without** exploit details and ask a maintainer how to share them privately.

Please do not open a public issue containing a working exploit.

## Scope

Only this fork is covered here. For the original mod, report to
[MCRcortex/nvidium](https://github.com/MCRcortex/nvidium). For rendering crashes that also occur without Nvidium,
report to [Sodium](https://github.com/CaffeineMC/sodium).
